# GEOMETRIC STRIKE

引っぱって、狙って、弾く。36種類の図形の仲間で戦うブラウザーゲームです。

## 起動・操作

`index.html` をブラウザーで開きます。ビルド・サーバー・インストール不要、オフラインで動作します。
タイトルからステージを選び、最大4体で出撃します。光っている味方を進行方向と逆に引っぱって離すと発射。味方はすり抜けて友情を発動し、壁では反射し、敵では撃種に応じて反射または貫通します。

- キーボード：左右で角度、上下で強さ、Spaceで発射、Escで一時停止。
- ゲージ100%でストライクバーストを使用できます。
- スコア・編成はブラウザーに保存。上部のボタンからヘルプ、音、一時停止、再挑戦を操作できます。
- 保存済みベストスコアは8-1/8-2のみ次回起動時に一度リセットされ、その他のステージの記録は保持されます。
- ステージ選択の「ステージ設定」から、全ステージ共通の無敵・攻撃力+3000・レーザージェネレーター・キューブ状態・ハートフルーツ無効の設定と、選択中ステージのベストスコアリセットを行えます。無敵中はダメージを受けず、スコアも記録されません。攻撃力+3000は編成キャラの攻撃力を上げ、レーザージェネレーターは既定倍率を使いますが、どちらも設定が有効なステージではスコアを獲得できません。ステージ側でレーザージェネレーターまたはキューブ状態が指定されている場合は、対応する共通設定を適用しません。
- 第1〜3章は各ステージ3エリア、第4章以降は各ステージ5エリア。エリアをまたいでも味方の位置と通常の所持フォトンを保持します。

## 主友情・副友情

味方への接触で主友情と副友情が両方発動します。味方の爆発・エナジーボールの爆風・壁ミサイルの爆風に触れた場合も両方を誘発します。通常は1ショットに1回、友情コンボ×2持ちは2回まで発動します。同じ接触や同じ爆風の連続ヒットでは重複発動しません。移動中のキャラ自身も爆風で誘発できます。敵の爆発や地雷では誘発しません。

副友情の基礎威力は個別設定です。主・副の両方に攻撃力、戦型、ストライクバースト、弱点の補正がかかります。編成画面に両方の説明を表示します。

- **反射分裂弾**：進行方向へ5発。壁に当たるたび二つに分裂して反射。各弾は最大3回分裂し、同時に最大40発。敵を貫通し、3回分裂後の次の壁接触または寿命で消滅します。
- **スクランブルレーザー**：周囲32方向からランダムに選び、45ミリ秒間隔で10本発射。各レーザーは最大2回、壁への到達に合わせて段階的に反射します。
- **トライデントウォールミサイル**：進行方向へ3way。敵を貫通し、壁に当たると半径255で爆発。ミサイルの接触と爆風でダメージを与え、爆風は味方の友情を誘発します。
- **爆発**：半径165から205へ約24%拡大。中心ほど多段ヒットし、範囲内の味方を誘発します。
- **エナジーボール**：敵への最初の命中で爆発。オービットの主友情は半径370（初期の2倍）、基礎威力750（以前の3倍）。
- **反射レーザー / 反射クロス**：進行方向、またはX字4方向へ発射。先端が壁へ到達してから次の区間へ進みます。
- **プラズマ**：友情所持キャラと移動中の味方をつなぎ、線上の敵へ連続ダメージ。移動終了で消えます。
- **メテオ(X)**：ランダムな生存中の敵へ順にX個落下。
- **拡散弾(X×Y)**：全方位XwayをY回発射。

## ステージとギミック

ギミック数は各エリアだけでなく、敵の散布も含めてステージ全体で数えます。基本2種類、最大3種類。敵配置の特徴は保持しています。

| ステージ | ギミック | 配置・特徴 |
|---|---|---|
| 1-1〜1-3 | なし | 基本戦闘、複数攻撃、弱点 |
| 1-4 | なし | 千鳥・斜めの列 |
| 1-5 | なし | 環状・螺旋 |
| 1-6 | なし | 丸い敵同士の隙間で連続反射 |
| 2-1 加速する転送路 | 加速パネル・ワープ | 転送ルート |
| 2-2 境界のラビリンス | ワープ・ダメージウォール | 危険な壁を避ける |
| 2-3 重力の岸壁 | 重力バリア・エナジーフォトン | 壁際の列・左側のボス |
| 2-4 地雷の結晶庭 | 地雷・加速パネル | 密集陣・地雷散布 |
| 2-5 双城の防衛線 | 重力バリア・ダメージウォール | 左右の砦・双ボス |
| 2-6 万象の反応炉 | 重力バリア・地雷・加速パネル | 圧縮陣・右上の核 |

2-4・2-5ではフォトンの初期配置と敵のフォトン散布を撤去。マインスイーパーは地雷の除去だけを行い、フォトンマスターは通常どおり有効です。

- 加速パネル：緑の四角に接触すると速度1.8倍、最低1200・上限2200。1.1秒は減速を軽減。各パネルにつき1ショット1回。
- ワープ：同番号の入口・出口を転送。方向と速度は維持。
- ダメージウォール：赤い壁の区間に触れるとダメージ。
- 重力バリア：青い円。敵が生存中、進入時に減速して内部でも継続減速。
- 地雷：赤い八角形。踏むと消えて1000ダメージ。敵も散布します。
- エナジーフォトン：黄色い菱形。各キャラ最大4個。直殴りで1個消費しダメージ2倍、友情では消費しません。弱点・戦型と乗算。満タンなら地面に残します。

## 戦型・弱点・敵の攻撃

- バランス型：被ダメージ20%軽減、直殴り20%増加。
- スピード型：各ショットで最初の壁接触時、一度だけ加速。
- パワー型：各ショットで最初の直殴り2倍。
- 砲撃型：主・副友情の威力2倍。

ボスの金色マーカーが弱点。直殴りも友情も、命中形状が弱点へ重なれば3倍になります。
敵は各攻撃に独立した1〜2ターンのカウントを持ち、複数が同時に0になれば同時発動します。

## 開発用ファイル

- `index.html`：画面とスクリプトの読み込み順。`styles.css`：レスポンシブデザイン。
- `js/core.js`：Canvas、共通定数、基本ユーティリティ。
- `js/data.js`：キャラクター、アビリティ、友情・敵攻撃の定義、編成位置。数値調整やキャラ追加はここ。
- `js/enemies.js`：敵のビルダー関数（foe/orb/core など）、雑魚の種類、十字／クロスレーザーの定義。
- `js/stages.js`：第1〜5章の全ステージ（1-1〜5-3）。ステージの追加・配置調整はここ。
- `js/enemy-gimmicks.js`：蘇生、ドクロ効果、弱点の付与・移動、ダメージ倍率、ギミック一覧の生成。
- `js/battle.js`：保存、戦闘状態、ステータス、音、ダメージ計算。
- `js/attacks.js`：友情と敵攻撃の発射・更新。ドローンの対象選択もここ。
- `js/friendship-ext.js`：新友情（クロスバウンドボム・アブソリュートクロスレイ・カウンターリング・ショットガン）の発射・更新・描画。
- `js/controls.js`：ターン進行、オーバーレイ、マウス・タッチ・キーボード操作。
- `js/simulation.js`：ギミック、衝突、移動、時間更新。
- `js/rendering.js`：Canvas描画、演出、アニメーションループ。
- `js/screens.js`：タイトル・編成・ステージ選択。
- `game.js`：起動処理と公開APIのみ。

ビルドやサーバーは不要です。`index.html` を直接開いて遊べます。`js` フォルダーも一緒に保存してください。各ファイルは通常のスクリプトとして共通スコープを共有し、`index.html` の `defer` 指定順（core → data → friendship → enemies → stages → enemy-gimmicks → battle → attacks → controls → simulation → rendering → screens → game）に実行されます。stages は data・enemies の後、battle の前に置く必要があります。共有定数は core/data、可変状態は battle にあります。起動用 game.js は最後に読み込みます。
- `CHARACTERS` / `SECONDARIES`：主・副友情。`abilitySets`：アビリティ。
- `STAGES`：敵配置とエリア。`STAGE_GIMMICKS`：第2章のギミック許可リスト。許可しない配置と散布攻撃を出撃データから除外します。
- `tests/mechanics.cjs`：実エンジンで物理・友情・ギミックと通しプレイを検証。
- `tests/smoke.cjs`：実ブラウザーでステージ選択、編成、PC・スマホ操作を検証。

テストはPlaywrightとChromeを使用します。別環境では`PLAYWRIGHT_MODULE`と`BROWSER_EXECUTABLE`でパスを指定できます。テスト用の内部APIはメモリ上にだけ注入し、配布ゲームには含めません。

## 第3章：ブロックと新友情

ブロックは灰色の固定障害物で、味方の移動を反射します。「アンチブロック」はこれをすり抜けます。狙い線も対応。友情の弾や爆風はブロックを通過します。移行先のブロックに味方が重なった場合は座標を維持し、一度外へ抜けるまでそのブロックだけ衝突を保留します。

- **3-1「隔壁の要塞」**：ブロック・ダメージウォールの2種類。点在する障害物を利用し、上・下・左右の危険な壁を避けます。3エリア。
- **3-2「分断された転送城」**：ブロック・ワープの2種類。全エリアで中央の壁が上下を完全に分断。対応するワープで上下を移動します。アンチブロックなら直接通過可能。アンチワープだけを持つ味方は転送されないので編成に注意。3エリア。

### 新友情の仕様

- **貫通弾（X）**：ランダムな敵へ矢印形の弾をX発。複数の敵を貫通し、1発につき各敵に1回命中。

- **ラウンドバースト**：友情所持キャラの位置を中心に、触れた味方が動く間、半径45から毎秒65ずつ最大340まで拡大。味方が止まるとその半径で爆発し、友情も誘発。
- **ドロップボム（X）**：フィールド内のランダムな地点へX個投げ、着弾時に爆発・友情誘発。
- **イラプション**：ランダムな敵の足元に炎柱。半径145の敵へ6回の連続ダメージ。
- **サンダー**：進行方向へ120度の扇状に電撃が拡大。最大480まで進み、各敵へ1回ダメージ。
- **コピー**：触れた味方の主友情だけをコピー所持キャラの位置から発動。威力補正はコピー所持キャラに基づきます。コピー同士は再帰発動しません。副友情は別に発動します。
- **スピードアップ**：触れた移動中の味方の方向を保って加速。1ショット1回、停止後は再始動させません。

反射クロスレーザーの括弧は反射回数、反射分裂弾・スナイパーショットの括弧は初期の弾数／狙撃対象数を示します。

## 章タブ・3-3 / 3-4

ステージ選択は「第1章」「第2章」「第3章」のタブ形式です。第1章は1-1〜1-6、第2章は2-1〜2-6、第3章は3-1〜3-6。各章で最後に選んだステージを画面内で保持し、左右キー・Home・Endでもタブを切り替えられます。バトルのキャラ欄には主友情・副友情の名前も表示します。

新キャラのアンチブロックはランス・リプル・パイアの3体に集約。アイリスとアークはアンチ重力バリア、エコーはフォトンマスター、ゼファーはマインスイーパーへ変更しました。

- **3-3「光子の重力環」**：重力バリア・フォトン・ブロックの3種類、3エリア。円形ボス「セレーネ」は毎ターン、弱点が下→右→上→左と移動。
- **3-4「転位する三角星」**：重力バリア・ワープの2種類、3エリア。中間は四角い双ボス、最終は三角形のボス「トリア」。最終ボスの弱点は上→右下→左下へ移動。

移動弱点は敵の攻撃が終わり、次の味方ターンが始まるときに切り替わります。ショットや敵の攻撃の途中では動かず、判定と表示が同時に変わります。新エリアに入った直後は初期位置から開始します。既存ボスの弱点は従来どおりです。

## 3-5・3-6と新友情・新アビリティ

- 3-5「崩れた幾何迷宮」：ギミックはブロックのみ。各エリア9個の不規則な隔壁を縫う3エリア。ボスは爆発・振動・反射レーザーの3攻撃。
- 3-6「雷壁の挟撃回廊」：ギミックは地雷のみ。初期30個を壁沿いに配置。敵も壁沿いに散布し、上限48個。中央の丸い敵同士の62pxの隙間で連続反射できる3エリア。ボスは地雷散布・振動・爆発の3攻撃。今後追加するボスは3パターンを基本にします。
- 敵の爆発は味方の友情を誘発しません。振動は周囲に一度ダメージを与え、短時間で外へ押し出します。外壁・ブロック・敵を越えて押し出さず、押し出し自体は友情や接触ギミックを誘発しません。
- マインスイーパーによるフォトン変換は廃止。地雷を除去するだけです。
- イラプションは揺れる複数の火柱、溶岩の飛散、煙、地面の閃光と衝撃波で噴火を表現。攻撃範囲・威力・6回のヒットは維持。

### 敵データの設定例

敵の `key` をエリア内で一意に付け、効果の `targets` で指定します。

```js
// 敵の攻撃パターン：2ターンごとに指定した敵を蘇生
{ kind: 'revive', targets: ['gel-a'], countdown: 2, interval: 2 }

// 敵のプロパティ：倒した際に指定した敵へ内部弱点を付与
skullEffects: [{ type: 'grantWeak', targets: ['boss'], internal: true, multiplier: 5 }]

// エリアのプロパティ：指定した敵を全て倒すと防御ダウン
crossSkulls: [{ id: 'seal', members: ['gel-a', 'gel-b'], effects: [
  { type: 'defenseDown', targets: 'nonRestriction', multiplier: 5 }
]}]
// 対象の敵には crossSkull: 'seal' を付けてマークを表示
```

`targets` は敵のkey配列のほか、`'all'`、`'nonRestriction'`、`{ group: 'seal' }` に対応。
`{ type: 'summon', keys: [...] }` はエリアの `reserves` に定義した敵を呼び出します。
`{ kind: 'effect', effects: [...], countdown: 2, interval: 2 }` を攻撃に指定すると、ドクロ以外でも防御ダウンや弱点付与を発動できます。

弱点倍率は敵→エリア→ステージの `weakMultiplier` の順に優先（省略時3）、フォトン倍率はエリア→ステージの `photonMultiplier` の順に優先（省略時2）。5倍・20倍など任意の倍率を設定できます。内部弱点は敵に `internalWeak: true` を指定します。

パワーエリア倍率は個別エリアの `multiplier` → waveの `powerAreaMultiplier` → ステージの `powerAreaMultiplier` の順に優先し、すべて省略した場合は4倍です。例えばステージ全体を4倍にするには `powerAreaMultiplier: 4` を指定します。

弱点移動は仕組みのみ実装し、4-4〜4-6には配置していません。同じ敵で移す場合は `weakMoveOnHit: true, weakAngles: [0, Math.PI]`。別の敵にも移す場合はエリアに次のように指定します。角度はラジアンです。

```js
weakRoutes: [{ id: 'relay', positions: [
  { target: 'enemy-a', angle: 0 },
  { target: 'enemy-b', internal: true },
  { target: 'enemy-a', angle: Math.PI }
]}]
```

直殴りの弱点ヒットで次の位置へ移り、最後まで進むと先頭に戻ります。倒された敵への移動は飛ばします。既存ステージの「ターンごとに移動する弱点」はそのままです。

## ハートフルーツ

壁沿いに出現する回復アイテム。自ターン終了のたびに抽選され、取らずにいると成長して回復量が増えます。

| レベル | 回復量 | 成長 |
|---|---|---|
| lv.1 | 2,000 | 生成直後 |
| lv.2 | 6,000 | 取らずに自ターンが1回終わるごとに成長 |
| lv.3 | 12,000 | 以降は成長せず残り続ける |

- **生成**：自ターン終了時（ショット終了時）に抽選。チームHPが51%以上なら10%、50%以下で20%、25%以下で30%。当選すると上下左右いずれかの壁の、ランダムな位置に接して出現します（四隅は避け、味方・他のフルーツと重ならない位置）。
- **同時数**：最大3つ。3つ存在するあいだは抽選自体を行いません。
- **成長と生成の順序**：自ターン終了時にまず既存のフルーツが成長し、そのあとで新規の抽選を行います。同じ瞬間に生成された実はlv.1のままです。
- **取得**：味方（手番キャラ、ウィンド等で動かされた味方）の体が触れるとチームHPを回復して消えます。回復は最大HPまで。HPが満タンでも触れれば消えます。友情の弾・爆風では取れません。
- **リセット**：エリアが変わると全て消えます（ハートパネルと同じ扱い）。

## 結界と 8-5 / 8-6

### 結界（新ギミック）
ステージ上の四角い翡翠色の枠。枠の上の数字は、壊れるまでに必要な残りの接触回数です。ステージ選択画面では青字で表示します。

- **外殻の当たり判定**：触れると壁と同じく反射します。枠の外にいれば中へ入れず、枠の中にいる味方は閉じ込められて内側の面で反射します。
- **破壊**：規定回数（枠の数字）触れると破壊され、そのショットのあいだは自由に通れます。最後の接触でも反射してから壊れます。壊れた枠は薄い破線で表示。
- **リセット**：結界と接触回数は毎ターン（次の手番開始時）に元へ戻ります。壊れていた結界の中や上に味方が止まっていた場合、次のショットでは中にいれば閉じ込められ、外殻をまたいでいれば外へ出る（中へ入る）まで衝突を保留します。
- **対象**：移動中の味方だけ。友情の弾・爆風や敵の攻撃は結界を通過します。アンチブロックでも結界は通過できません。壁接触（スピード型の加速・カウンターリング等）には数えません。
- **狙い線**：外側／内側の反射に対応（触れ回数が規定に達した結界はその先で消える）。
- **データ**：エリアの `gimmicks.barriers: [{x,y,w,h,n}]`。ロジックは `js/simulation.js`（`applyBarriers`）、描画は `js/rendering.js`（`drawBarrierFills` / `drawBarrierFrames`）。ステージ選択では青字の「結界」。

### 8-5 閉ざされた結界の回廊
ブロック（赤字）・結界（青字）・剣パネル・加速パネル・ハートパネル・撃種変化パネル（ボス2のみ）・内部弱点（ボス2のみ）。道中3＋ボス2の5エリア。丸型の雑魚には円・三角・五角・六角・八角の形状があり、四角い雑魚はそのままです。中ボスは四角、ボス「ヴェール」は六角形で、サイズは従来どおりです。結界の中には敵・剣パネル・ハートパネルが隠れています。道中1の右下の大きな結界は味方の初期位置を含むため、最初は閉じ込められた状態で始まります。ボスの弱点は、ボス1が下、ボス2が内部弱点で、ボス2は3ターンごとに結界の中へ移動します。中ボスの弱点は上下を毎ターン交互に切り替えます。

### 8-6 三十倍の起動と十八倍の弱点
減速壁（4面）・反射制限／貫通制限・パワースイッチ（30）・撃種変化パネル・内部弱点・弱点倍率18。灰色が貫通制限、水色が反射制限、内部弱点は黄色い点を持つ敵です。丸型の雑魚には円・三角・五角・六角・八角の形状があります。制限敵・中ボス・ボスはパワースイッチを全て2にしないと、ほとんどダメージが通りません（`switchArmor:.02`）。制限敵は3ターンごとに互いを蘇生します。ボス「リミット」は従来どおりの大きさで、弱点はボス1が上↔左、ボス2が右↔下。

座標はスライドの目視換算（`js/stages.js` 末尾）。ステージ名・ボス名・HPは仮値です。敵の表示は、下の壁（ダメージウォール）付近でHPバーが盤面の外へ出る場合、敵の体の内側に表示します（8-1ボス2対策）。

## 第9章：レーザージェネレーター / 9-1 / 9-2

### レーザージェネレーター（新ギミック）
ステージの `laserMultipliers`（レベル別の倍率）がある場合のみ有効。専用の機械的で幾何学的な壁（盤面の外周の帯）で描画され、上下の帯に設置数（n/4）とレベル別の倍率を表示します。ステージ選択では青字の「レーザージェネレーター」。

- **設置**：上下左右の各辺で、手番キャラが**最初に触れた壁**にその場所で1基ずつ設置されます（同じ辺の2回目以降は無視。角に触れると2辺に同時設置）。設置は毎ショットで、設置済みのレーザーの通り道は薄い帯で予告されます。
- **発射**：手番キャラが停止すると、溜め（約0.45秒）のあと、設置された全基が壁に垂直なレーザーを**一斉に3回**発射します。レーザーは友情コンボ風の発光と白い芯で描き、色は手番キャラのカラーに合わせます。演出が終わるまで次の手番へ進みません。
- **レベルと威力**：設置数がレベル（1〜4）。威力＝手番キャラの攻撃力×攻撃力アップ×ウォールブースト×ステージ倍率（9-2 は Lv.1〜4 で ×1／×2／×8／×24）。キラーや弱点など敵ごとの倍率も命中時に適用します。フォトンは適用・消費しません。太さもレベルで 20／34／48／72。ステージ選択の「パワー+3000」設定にも連動します。
- **命中**：太さぶんの帯に体が触れた敵にダメージ（1本ごと・1回ごとに1ヒット）。帯が弱点に触れると弱点倍率が掛かり、内部弱点にも届きます。**反射／貫通制限の軽減は受けません**。透明な敵・剣持ち敵は対象外。
- **データ**：`stage.laserMultipliers`（または wave 側）。定数は `js/data.js` の `LASER_GENERATOR`（発射回数・溜め・間隔・太さ・既定倍率・`damagePerPower`）。ロジックは `js/simulation.js`（`placeLaserGen` / `fireLaserGens`）、ダメージは `js/attacks.js`（`updateLaserGen`）、描画は `js/rendering.js`（`drawLaserWalls` / `drawLaserGens` / `drawLaserGenEffect`）。

### 9-1 蘇る大群と九倍の弱点
重力バリア・結界・蘇生・弱点倍率9。敵の数が多く（最大18体）、雑魚は柔らかめで、雑魚とボスは四角。紫の蘇生役とボス「ヒドラ」は、毎ターン倒れた雑魚を3体まで蘇生します。蘇生役とボスは大きな重力バリアを持ち、結界の中に隠れています。ボス1は弱点が上下交互、ボス2は左右交互で3ターンごとに移動します。

### 9-2 四つの砲台と二十倍の弱点
地雷・反射制限・レーザージェネレーター・蘇生・クロスドクロ・弱点付与・内部弱点・弱点倍率20。紫の蘇生役（内部弱点）は2ターンごとに倒れた敵を全て蘇生します。ボス戦（ボス「ジェネシス」）では、蘇生役を全員倒すとボスに弱点が付きます（ボス1は内部弱点、ボス2は左右の弱点）。

座標はスライドの換算値（敵が盤面の端に接する配置のため、盤面の外側ではなく内側 28〜592 × 28〜712 へ合わせています。`js/stages.js` 末尾）。ステージ名・ボス名・HPは仮値です。

検証: `node tests/laser-chapter9.cjs`（設置・発射・威力・弱点・制限の軽減なし・リセット、9-1/9-2の構成・ギミック表示・蘇生・クロスドクロ、全10エリアの通しプレイ）。
